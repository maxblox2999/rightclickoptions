# RightClickOptions

Archived Windows 10 utility that adds file and folder actions to the Explorer context menu.

## Actions

| Action | Behavior |
| --- | --- |
| Force Delete | Stops processes locking the selected item, then permanently deletes it without using the Recycle Bin |
| Open with Notepad | Opens the selected file in Notepad, including executable and library files |
| Copy Full Path | Copies the selected item's absolute path |
| Take Ownership | Changes ownership and permissions for the selected file or folder; this action is known to be unreliable |

Force Delete is permanent. Check the selected path before using it.
